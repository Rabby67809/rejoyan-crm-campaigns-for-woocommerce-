Rejoyan CRM & Campaigns for WooCommerce — Changelog

= 1.0.0 =
* Finalized the first WordPress.org submission release.
* Resolved pre-submission Plugin Check findings for translator comments, nonce verification, input sanitization, custom-table identifier escaping, caching annotations and uninstall variable prefixing.
* Added server-side marketing-permission confirmation to standard queued campaigns.
* Hardened CSV report cells against spreadsheet formula execution.
* Reworked release documentation and human-readable assets for WordPress.org review.
* Preserved all v0.8.0 automation, scheduling, retry, System Health, smart-segment, product-linked template and live-product Social Studio functionality.

= 0.8.0 =
* Added future scheduling for standard campaigns and saved-offer email sends using Action Scheduler when available with WP-Cron fallback.
* Added offer start/end validity windows and blocked unavailable offers from sending and product CTA resolution.
* Added product-buyer campaign targeting using real WooCommerce purchase history.
* Added full HTML campaign preview in a separate admin-safe view.
* Added retry-failed-recipient workflow without re-sending recipients already marked sent.
* Added a dedicated System Health page with queue, cron, schema, WooCommerce and sender checks.
* Added scheduled campaign status/time display in campaign history.

= 0.7.0 =
* Rebuilt Social Studio around live published WooCommerce products from the current website; no demo or fake products are inserted.
* Added AJAX product search, category filtering, sale/stock filtering and Load More pagination.
* Added live product count, category/SKU metadata, stock state and direct View Product actions.
* Added premium self-contained 3D-style share controls for Facebook, X, LinkedIn and WhatsApp without external icon/CDN assets.
* Added device-native Web Share support with a copy fallback when the browser does not support native sharing.
* Kept product images lazy-loaded and product catalog queries batched for large-store performance.

= 0.6.1 =
* Added shell-first admin rendering so Rejoyan CRM & Campaigns screens paint before expensive store data is queried.
* Added deferred AJAX panels for Dashboard, Email Center, Segments, Campaign History, Social Studio, Analytics and Invoices.
* Added viewport-aware loading with IntersectionObserver so below-the-fold campaign history waits until needed.
* Restricted WooCommerce enhanced-select assets to the Offers screen where product search is actually used.
* Added native lazy-loading and async decoding for Social Studio product images.
* Primed customer user-meta cache before rendering the Email Center to reduce per-customer metadata queries.
* Added deferred script loading for the Rejoyan CRM & Campaigns admin bundle.
* Stopped loading Rejoyan CRM & Campaigns admin/report classes on customer-facing storefront requests.
* Added retry handling for deferred admin panels.

= 0.6.0 =
* Added six ready-made offer email templates: Flash Sale, New Arrival, VIP Exclusive, Weekend Deal, Product Spotlight and Back in Stock.
* Added WooCommerce product linking to reusable offers using WooCommerce product search.
* Added live product name, price and image support inside offer emails.
* Added product placeholders: `{{product_name}}`, `{{product_price}}` and `{{product_url}}`.
* Added a non-logging local offer redirect that opens the linked WooCommerce product.
* Added optional WooCommerce coupon auto-apply behavior using the customer cart/session, including after add-to-cart when needed.
* Added linked-product details to the saved offer library.
* Updated the offer builder UI, WordPress.org metadata and database schema for product-linked offers.


= 0.5.1 =
